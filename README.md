## Описание

Проект представляет собой интернет-магазин, работающий на локальном хосте по адресу 127.0.0.1:8000, и имеющий две страницы: ***Каталог*** и ***Контакты***.
Страницы представляют собой ***html*** файлы, с подключенными стилями ***Bootstrap***.

Выполнена настройка подключения к базе данных PostgreSQL.
Все конфиденциальные переменные, такие как ***SECRET_KEY***, ***DEBUG*** вынесены в файл .env. Такой файл необходимо создать вручную в корне проекта по образцу
представленному в файле ***.env.sample***.

Реализованы и зарегистрированы модели ***Category*** и ***Product***. Созданы соответствующие миграции.

В админ панели создан суперпользователь.

Созданы фикстуры ***category_fixture.json*** для категорий и ***product_fixture.json*** для продуктов. Они упрощают добавление новых категорий и товаров, так как отражают необходимый шаблон для добавления новых элементов.

Созданы базовый шаблон, подшаблон для навигационного меню.

Создана страница для одного товара, настроено корректное отображение изображения товара.

Настроен медиа фильтр.

Представления ***FBV*** приложения ***Catalog*** переведены в классовые представления ***CBV***.

Создано приложение для статей ***Blogs***. Главная страница статей открывается по клику на ссылке ***Мы пишем*** в футере страницы в разделе ***Блог***.

В приложении ***Blogs*** переопределены некоторые методы:
- ***get_object*** для реализации счетчика просмотренных статей,
- ***get_queryset*** для фильтрации опубликованных статей.
